# Feelsie

Feelsie sends one daily email and records mood, energy, sleep, and an optional note.

The core package contains configuration, local-date logic, token generation, prompt authorization,
and SQL operations. The Cloudflare Workers remain proposed.

## Commands

```bash
vp install
vp run ready
vp exec fallow
```

Read [`ABSTRACT.md`](./ABSTRACT.md) for the system outline. Read [`AGENTS.md`](./AGENTS.md) for

# Catalog

Empty, and empty on purpose.

The catalog is present tense: it states what feelsie promises **now**. A claim is in it only if
a sound witness affirms it, and a claim enters in the same merge that makes it true. No code
exists yet, so no witness affirms anything, so there is nothing here.

The promises that `ABSTRACT.md` used to hold are not gone. They are **proposed**, and a
proposal lives outside the catalog until the merge that enacts it:

| State                  | Can you write the claim? | Where it lives                                       |
| ---------------------- | ------------------------ | ---------------------------------------------------- |
| **fog**                | no                       | [`.scratch/fog.md`](../../.scratch/fog.md)           |
| **proposed amendment** | yes                      | [`.scratch/amendments/`](../../.scratch/amendments/) |

Resist the urge to seed this directory with what you intend to build. A catalog that holds
intent has no meaning, because every entry in it might be a lie and nothing distinguishes the
ones that are.
